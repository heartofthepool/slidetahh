# SLIDETAHH

Small details, big impression — slide trình chiếu Grooming (BROWS) cho Sun PhuQuoc Airways.

Mở `index.html` bằng Chrome/Edge, bấm **Bắt đầu trình chiếu**.

- → / Space / clicker: bước tiếp · ←: lùi
- Gõ số slide + Enter: nhảy slide
- N: lời thoại · E: sửa chữ · F: toàn màn hình · H: trợ giúp

Bản này không dùng hiệu ứng blur (tối ưu độ mượt).
